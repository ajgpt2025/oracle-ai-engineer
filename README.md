# 🤖 Oracle AI Engineer

An AI-powered Oracle Database and Oracle APEX assistant built with Python, Ollama, and local LLMs.

---

## 🚀 Features

- 💬 Local AI Chat (Qwen via Ollama)
- 📝 Oracle SQL Generator
- ⚡ SQL Optimizer
- 🛠 Oracle Error Explainer
- 🌐 Oracle APEX Assistant
- 📊 Oracle Database Connector *(Coming Soon)*
- 📄 PDF Knowledge Base *(Coming Soon)*
- 📈 Excel & CSV Reader *(Coming Soon)*

---

## 🛠 Tech Stack

- Python 3
- Ollama
- Qwen
- Streamlit *(Coming Soon)*
- Oracle Database
- Git
- VS Code

## ▶️ Run the Project

Activate your virtual environment:

```bash
source .venv/bin/activate
```

Run the application:

```bash
python app.py
```
